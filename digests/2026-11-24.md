# Agentic Radar — 2026-11-24

## What happened
- [1055] Anthropic launched Claude Ship on Nov 23 in beta for Claude Team and Enterprise on GitHub: Code Review is generally available, PR Steward fixes CI failures and merge conflicts, and Claude Approvals can auto-approve routine changes under a policy file in the repo. [announced-coming]
- [1056] Claude Code 2.1.331, released Nov 23, adds Code Mode support in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and Claude Platform on AWS, plus API connectivity checks in `claude doctor`. [announced-live]
- [1058] Codex CLI 0.172.0, released Nov 24, adds thread links to saved conversations and nested agents, Tab completion for slash-command arguments, task-group navigation, and lazy startup for optional stdio MCP servers on first tool call. [announced-live]

## Why it matters
- [1055] Claude Ship moves Anthropic from writing code to deciding when code ships: an agent that can approve changes under a written policy is a governance product, not just a review assistant, and the observe-only recommendation shows the trust boundary is the feature.
- [1058] Codex 0.172.0 is workflow plumbing that compounds: thread links, lazy MCP startup and per-tool approval reviewers reduce friction in long agent sessions without changing the model.
- [1056] Code Mode reaching Bedrock, Agent Platform, Foundry and Claude Platform on AWS in 2.1.331 means the experimental tool-calling mode is now a cross-cloud terminal feature, not a first-party-only preview.

## Connections
- [1055] <-> [1056] — rhymes — Claude Ship's approval agents and Claude Code's Code Mode expansion both extend Claude's role beyond generation, Ship into merge decisions and 2.1.331 into multi-cloud tool execution; they share a vendor, not a mechanism.

## Where this points
- [bullish] [1055] Policy-based auto-approval, run observe-only first, is a credible path for routine PRs to merge without a human in the loop — builders who write clear approval policies will get the leverage first.
- [bearish] [1055] An approving agent also concentrates risk: a loose policy file in a repo becomes an attack and error surface, so audit trails for agent approvals become mandatory, not optional.
- [bullish] [1058] [1056] Lazy MCP startup and cross-cloud Code Mode lower the session-start cost of agent tools, making long, tool-heavy sessions the default workflow.
