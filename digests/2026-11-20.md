## Why it matters
- [1017] Computer use puts a general agent on the desktop itself — every Mac app and file becomes its surface, with app permissions and live preview as the control model.
- [1018] Tool Retrieval attacks the scaling cost of large tool catalogs: schemas load only when a task needs them, which is the plumbing that makes hundred-tool agents affordable.
- [1015] The Performance Factory is production evidence: diagnosis scaled, but only about 15 of roughly 400 proposed fixes shipped as exact agent PRs — trust is being earned in narrow work first.
