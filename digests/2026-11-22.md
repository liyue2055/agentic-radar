# Agentic Radar — 2026-11-22

## What happened
- [1031] OpenAI's Agents API now supports Daybreak Blue and Red sessions as of Nov 21, via an access_programs.cyber field in the official docs guide, pairing gpt-6-sol with daybreak_blue and gpt-5.6-cyber with daybreak_red. [announced-live]
- [1030] OpenAI released GPT-Live-1.1 in the API on Nov 19, per its official changelog, improving pronunciation, accent consistency and multilingual transcription, and adding standby mode that pauses WebRTC inference during inactivity. [announced-live]
- [1029] Claude Code 2.1.328, released Nov 19, adds auto mode for Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and the Claude apps gateway, per the official changelog; sessions with no permission mode set now start in auto mode.
- [1033] OpenAI will retire Advanced and Standard Voice from ChatGPT Voice on Dec 11, 2026, per its official help page; users were notified on Nov 10 and voice will default to GPT-Live after that date. [announced-coming]
- [1032] Meta claims its Ranking Engineer Agent now handles over 60% of technique propagation across ads ranking models, with an estimated $45M+ in compute savings by the end of the year, in a Nov 18 engineering blog post. [older] [single source] [case-study]

## Why it matters
- [1031] Cyber-capable agent sessions are now a configured API option, not a bespoke engagement: access programs are part of the session schema itself.
- [1029] Auto mode as the default starting mode on third-party clouds moves permissions from opt-in to default-on autonomy, shifting review onto admins.
- [1030] [1033] GPT-Live-1.1 in the API, with a Dec 11 retirement date for Advanced and Standard Voice, consolidates voice agents onto one full-duplex stack.

## Connections
- [1030] <-> [1033] — continues — GPT-Live-1.1's Nov 19 API release precedes the Dec 11 retirement of the older Advanced and Standard Voice modes, which default users to GPT-Live.
- [1029] <-> [1032] — rhymes — Claude Code's auto mode default on third-party clouds and Meta's agents driving production technique propagation both make autonomous execution the default inside managed workflows.
- [1031] <-> [1029] — rhymes — Daybreak access programs configured in agent sessions and Claude Code's permission mode default both put security configuration inside the agent session setup.

## Where this points
- [bullish] [1031] [1030] Session-level configuration — cyber access tiers, Live standby — is becoming the agent control plane, favoring builders who design around session policies.
- [bearish] [1033] The Dec 11 voice retirement is a hard migration deadline: products built on Advanced or Standard Voice lose that mode in under three weeks.
- [bullish] [1029] [1032] Default-on autonomy in managed settings raises the value of audit and approval tooling around agents that are already running in production.
