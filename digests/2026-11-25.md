# Agentic Radar — 2026-11-25

## What happened
- [1072] Anthropic launched Install as app on Nov 24 in beta for Claude for Mac and Windows: an artifact gets its own window and icon, can use Claude and connectors, and asks for one of three permission levels, including full computer access. [announced-coming]
- [1071] Claude Code 2.1.332, released Nov 25, adds skills from MCP servers in beta, shown as server:skill in the / menu, and a PreSkillShellCommand hook that can refuse a skill's inline shell commands as it loads; the sonnet alias on Agent Platform and Foundry moves to Sonnet 5.5. [announced-live]

## Why it matters
- [1072] Install as app turns artifacts from outputs shared inside Claude into desktop software a user opens daily, with no packaging or signing step. The permission tiers are the product: default and app permissions keep the app sandboxed, while full computer access is limited to apps you made or, on Team and Enterprise, apps from your own organization.
- [1071] MCP server skills extend Claude Code's skill system beyond local files: a server can now distribute skills that appear alongside local ones. The PreSkillShellCommand hook is the matching control, letting a setup refuse a skill's inline shell commands at load time rather than after they run.

## Connections
- [1072] <-> [1071] — rhymes — both expand what Claude can load and run on a user's machine, Install as app at the desktop surface and 2.1.332 at terminal skill loading; they share a vendor, not a mechanism.

## Where this points
- [bullish] [1072] Artifact apps give non-developers a distribution path for small Claude-built tools: describe, install, share, with updates flowing from the underlying artifact.
- [bearish] [1072] Full computer access for apps Anthropic does not review concentrates risk in the permission prompt: a trusted app that is later edited asks again, but a user who clicks through once gives it program execution and file access.
- [bullish] [1071] Skills distributed by MCP servers make skill sharing a server feature rather than a file-copying exercise, which should grow the skill ecosystem around Claude Code.
