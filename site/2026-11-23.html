Agentic Radar — 2026-11-23

What happened

[1038]
Z.ai rolled out GLM-5.4 to all GLM Coding Plan subscribers on Nov 23, adding vision input absent from GLM-5.3 and a 1M-token context via `glm-5.4[1m]` in Claude Code, with 50% more weekly quota; the API and open weights are pending a safety review. [announced-live]
[1043]
Anthropic launched Computer Use in beta for Claude Team and Enterprise plans on Nov 20, per its release notes via support.claude.com: Claude can see the user's screen and work in allowed desktop apps across Claude Desktop, web and mobile, off by default and owner-gated, rolling out gradually. [announced-live]
[1045]
OpenAI shipped GPT-6.2 Astra and Sol on Nov 17 per its launch post: Astra at $8/$40 per Mtok (20% below GPT-6 Astra, cached input discounted 60%) and Sol as the $2/$10 default; both models are rated Critical on cybersecurity under the Preparedness Framework. [announced-live]
[1042]
Codex CLI 0.171.0, released Nov 20 per OpenAI's official changelog, adds GPT-6.2 Sol and Astra to the model catalogs with Sol as the default selection, enables the TUI workspace by default with document and image previews and subagent transcripts, and adds `codex exec --remote` plus /rc remote-control pairing. [announced-live]
[1047]
Google launched Gemini 4 Neon on Nov 18 for coding, analysis and long-running agents at $3/$15 per Mtok with a 1M-token context, rolling out through the paid Gemini API, AI Studio, Gemini for business, and the Gemini app and Antigravity for Pro and Ultra subscribers; a cyber-focused variant is reserved for Fairwind Program defenders. [single source]
[1049]
Moonshot open-sourced Kimi K2.6 on Nov 21 per the Kimi blog, focused on long-horizon coding, coding-driven design, proactive agents and agent swarms, with a Claw Groups research preview; it is available via Kimi.ai, the Kimi app, the API and Kimi Code, with parameter count and pricing not disclosed in the release text. [single source]
[1041]
Claude Code v2.1.330, released Nov 20, adds easel, a built-in mod that draws charts on request and under MCP metrics results on Pro, Max and, where available, Team and Enterprise, plus sign-in to organizations managed in Anthropic's Enterprise Admin Console. [older]

Why it matters

[1038] GLM-5.4 ends the Radar's multi-week non-release watch on Z.ai's next flagship: instead of the rumoured GLM-5.5, Z.ai shipped a 5.4 that loops 28 GLM-5 layers twice — depth without new parameters — and put it straight into the subscription coding plan developers already use, ahead of any API or weights release.
[1043] Computer Use moving from individual Pro/Max plans to Team and Enterprise is the enterprise-governance version of the same capability: the control surface (off by default, owner-only activation, per-user opt-in) is the product, because there is no sandbox between Claude and the user's applications.
[1045] [1042] GPT-6.2 Sol becoming Codex's default catalog selection the same week it ships puts OpenAI's newest default-tier model into the terminal agent immediately, rather than behind a model-picker change most users never make.
[1047] Neon extends Google's Gemini 4 family pricing ladder (Hydrogen $1.50/$7.50, Carbon $2/$10 introductory, Neon $3/$15) into a dedicated long-running-agent tier, with the cyber variant again gated to vetted defenders first.
[1049] K2.6 pushes the open-weights coding race toward long-running, multi-tool engineering loops and agent swarms, but the release text withholds the parameters, pricing and checkpoint details builders need to evaluate it against GLM-5.4 and Mistral Large 4.
