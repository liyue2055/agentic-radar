Why it matters

[1085] MCP server skills extend Claude Code's skill system beyond local files: a server can now distribute skills that appear alongside local ones, and the PreSkillShellCommand hook is the matching control, letting a setup refuse a skill's inline shell commands at load time rather than after they run.
[1087] Codex's release is about supervising parallel agent work: thread links, task-group navigation and lazy MCP startup all reduce the friction of running several nested agents from one terminal.
[1095] A 20% frontier price cut with a deeper cache discount lowers the per-task cost of long agentic runs, while the Critical cybersecurity classification keeps the strongest safeguards attached to the most capable tier.

Connections

[1085] <-> [1087] — shared mechanism — both releases extend MCP in the terminal agent: Claude Code loads skills distributed by MCP servers, while Codex starts optional MCP servers lazily on first tool call and adds per-tool approval reviewers for connected apps.

Where this points

bullish [1085] Skills distributed by MCP servers make skill sharing a server feature rather than a file-copying exercise, which should grow the skill ecosystem around Claude Code.
bearish [1085] Server-distributed skills widen the supply chain for code that runs in a developer's terminal; the load-time hook exists precisely because that trust decision now happens automatically.
bullish [1087] Lazy MCP startup and per-tool approval reviewers make it practical to keep more tools connected to a coding agent without paying startup cost or giving blanket approvals.
bullish [1095] Cheaper cached input rewards long-context agent loops that re-read the same working set, pushing frontier economics toward persistent sessions.
