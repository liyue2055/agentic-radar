Agentic Radar — 2026-11-27

What happened

[1108]
Anthropic's Nov 25 engineering post says it migrated the Messages API from Python to Rust: Claude wrote the first core path in about a week, the production API served as the verifier with agents dispatched to fix differences, and the Rust service uses about 70% less CPU per request with about 20% lower median time to first token. [announced-live]
[1107][1119]
Google made its Workspace MCP servers and official Workspace CLI generally available on Nov 24, covering Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat and Tasks, alongside a Cloud Agent Gateway; a new AI Tools Addendum requires agents to use MCP or the CLI rather than REST APIs, with technical enforcement from Feb 1, 2027 and Scaled-tier billing from Apr 1, 2027. [announced-live]
[1109][1120]
Claude Duet's research preview expanded beyond the US on Nov 25 to India, Indonesia, Brazil and Japan: Anthropic's product page lists waitlist access for Pro, Max and Ultra subscribers in all five countries, on Opus 5.5. [announced-live]

Why it matters

[1108] The method is the story: the hard part was not generating the rewrite but proving parity, so Anthropic fingerprinted differences against live production traffic and dispatched agents to fix each new class — a reusable pattern for agent-led rewrites.
[1107] Workspace is where office agents actually work, and Google is making MCP the only sanctioned door into it: every agent builder on Gmail, Drive or Calendar now has a dated migration deadline and, from April, a metered tier to plan around.
[1109] Duet is Anthropic's proactive work agent leaving its home market four weeks after the US preview — the consumer-agent race is now being run market by market, not just feature by feature.

Where this points

bullish [1107] A platform-mandated MCP door with policy checks on every request makes Workspace agent access governable at enterprise scale, pulling more agent workloads onto Google's terms rather than around them.
bearish [1107] Partner-gated tools already visible in the GA servers — Gmail send, reply and forward are not generally available — mean the mandated door is narrower than the REST APIs it replaces until partner access widens.
bullish [1108] A verified 70% CPU cut on the API path lowers the unit cost of every Claude Code and API session, and the verifier pattern gives other labs a template for agent-led infrastructure rewrites.
bearish [1109] Duet still runs as a waitlisted preview that Anthropic itself says can misread threads and urgency; international expansion widens exposure to those failure modes before general availability.
